# S2.1 reevaluation triage (first pass)

Per-module keep-and-harden / refactor-in-place / rewrite classification and priority order for the
intelligence-core rebuild (backlog S2.1; ADR 0008; PRD 0001).

## Method and caveat

This first pass classifies from **objective signals**: module size (a disorder proxy), the presence
of dedicated tests (a behaviour-coverage proxy), architectural role, and the findings made while
building the Phase 0 safety net. **It is not a substitute for reading each module.** Whether a large
module is genuinely tangled or merely big must be confirmed by reading it before any split. Per-module
coverage numbers were not available (pytest-cov is not installed; that is Phase 1 / S1.2).

## Headline finding

The codebase has **broad test coverage (61 test files)** and the highest-risk science
(`rs_analysis`, the `rs_imagery` adapters, `rs_sync`) is well-tested and parity-checked. The reported
"disorder and bugs" are concentrated in a handful of **oversized modules**, not in broken logic. So
the rebuild is mostly **keep-and-harden plus targeted refactor-in-place**, with **no obvious
rewrites**. That is the cheap, low-risk path.

## Refactor-in-place (oversized; split into focused units under existing + characterization tests)

Priority order, worst-disorder-density first. Behaviour held constant; add characterization tests
(S0.3) for any weakly-covered path right before splitting it.

1. **`packages/rs_core/repositories.py` (985 lines)** the largest module by far, almost certainly a
   god-module spanning many aggregates. Split by aggregate (farm, field, analysis, scene,
   interpretation, annotation, collection-state). Pinned by `test_repositories` plus the DB suites.
2. **`services/worker/tasks.py` (613)** likely bundles collection / interpret / publish / monitor
   Celery tasks. Split by domain. Pinned by `test_tasks`, `test_tasks_db`.
3. **`services/api/workspace.py` (644)** the BFF (INTERNAL-IMPROVABLE, free to restructure). Split
   routers by resource (farms, fields, interpretations, annotations, analyse). Pinned by
   `test_workspace_db`; the contract gate does not freeze it.
4. **`services/api/ingestion.py` (466)** large; consider splitting validation / mapping / persistence
   (AgriTrack mapping already lives in `integrations.py`). Pinned by `test_ingestion_db`,
   `test_ingestion_logic`.
5. **Assess, then split only if tangled:** `rs_core/alerts.py` (327), `rs_sync/agritrack.py` (270).
