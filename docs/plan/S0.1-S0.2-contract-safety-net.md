# Plan — S0.1 + S0.2: the contract safety net

- Status: plan (read-only design; no product code yet)
- Date: 2026-06-10
- Slice source: `docs/backlog/0001-intelligence-core-rebuild-backlog.md` (S0.1, S0.2)
- Decisions: PRD 0001 Appendix A (R19, R20, R21, R22, R29); ADR 0008

## Goal

Freeze the external boundary in an enforceable form before any rebuild touches code: a deterministic
snapshot of the current external API, a human-readable `CONTRACT.md` classifying every route, contract
tests over the frozen set, and a CI diff gate that turns drift into a failing test.

## The external surface, classified

Resolved from `services/api/main.py` (router includes), `integrations.py` (prefix `/api/v1/mobile`),
`ingestion.py`, `operations.py`, `workspace.py`, and `rs_sync`.

**EXTERNAL-FROZEN (served routes):**
- `POST /api/v1/mobile/sync` (`integrations.py`) — AgriTrack farm/field/sub-plot sync (the real
  inbound onboarding path; maps their shape to `FarmIn`, then `ingest_farm`). Auth: `X-Api-Key`
  (`RS_AGRITRACK_API_KEY`).
- `GET /api/v1/mobile/data` (`integrations.py`) — AgriTrack results pull (`list[SatelliteResult]`).
  Auth: `X-Api-Key`.
- `POST /farm` (`ingestion.py`) — generic vendor-neutral ingestion (`FarmIn` -> `FarmIngestReport`).
  **FROZEN-CANDIDATE**: confirm whether the live gateway calls this or only `/api/v1/mobile/sync`
  (see Risks).

**EXTERNAL-FROZEN (outbound wire format, not a served route):**
- Results push: `rs_sync.build_payload` / `to_satellite_results` (`SatelliteResult`,
  `PublishedNarrative`) -> `POST {RS_AGRITRACK_BASE_URL}/integrations/satellite/results`, header
  `X-Api-Key`. Also the bearer push to `RS_GATEWAY_PUSH_URL` when `RS_GATEWAY_ADAPTER=http`.

**INTERNAL-IMPROVABLE (we own both ends; not frozen):**
- All of `workspace.py` (the BFF): `/farms`, `/farms/{id}/publish`, `/farms/{id}/publish/status`,
  `/farms/{id}/fields`, `/fields/{id}/timeseries`, `/fields/{id}/scenes`,
  `/fields/{id}/interpretations`, `PATCH /fields/{id}/interpretations/{iid}`,
  `/interpretations/review-queue`, `/fields/{id}/audit`, `/fields/{id}/collect`,
  `/fields/{id}/annotations` (GET/POST), `DELETE /annotations/{id}`, `POST /analyse/aoi`.
- `operations.py`: `POST /publish/farm/{id}`, `GET /pipeline/health`.
- `main.py`: `/healthz`, `/readyz`. Tiler: `/healthz`, `/tiles/...`.

## File-by-file change list

- NEW `contract/snapshot_openapi.py` — imports `services.api.main:app`, writes `app.openapi()` to
  `contract/openapi.before.json` with sorted keys and stable ordering (deterministic).
- NEW `contract/openapi.before.json` — the frozen snapshot (generated artifact, committed).
- NEW `CONTRACT.md` (repo root) — the classification table above; the exact request/response schemas
  of each frozen route (`FarmIn`, `FieldIn`, `FarmIngestReport`, the AgriTrack `_FarmSyncIn` family,
  `SatelliteResult`, `PublishedNarrative`); the auth headers (`X-Api-Key` inbound and outbound, the
  outbound bearer); the full list of `RS_*` env var names from `rs_core/config.py`; and the rule that
  a non-additive change to a frozen route or the outbound payload is a regression.
- NEW `tests/contract/test_frozen_routes.py` — for each frozen route, assert method, path, status
  code, required request fields, and response-model fields; assert `X-Api-Key` is required
  (401/403 without it). `TestClient` + dependency overrides for `get_session`/auth so it runs
  zero-network, zero-DB (testability invariant).
- NEW `tests/contract/test_outbound_payload.py` — snapshot the serialized `SatelliteResult` /
  `build_payload` output against a committed golden, so the outbound wire format cannot drift silently.
- NEW `tests/contract/test_openapi_diff.py` — regenerate `app.openapi()`, diff against
  `openapi.before.json`, fail on any removal, rename, required-field add, type change, or status-code
  change on an EXTERNAL-FROZEN path; allow additive changes; ignore INTERNAL-IMPROVABLE paths.
- EDIT `.github/workflows/ci.yml` (and the Azure pipeline) — run `tests/contract/` plus the diff gate
  on every push and PR.

## Test strategy

- The contract tests pin the external shapes exactly as they are today (characterization, not
  aspiration). They are the regression net the refactors and rewrites are proven against (R29).
- The diff gate is the machine check; `CONTRACT.md` is the human-readable intent. Both are required.
- Everything stays in the fast unit lane: `TestClient` + overridden `get_session`/auth dependencies,
  no DB or network.

## Risks and confirmations

- **POST /farm live usage.** Is it a live external endpoint or superseded by `/api/v1/mobile/sync`?
  Over-freezing an internal endpoint would block valid cleanup. This is an external-team fact, like
  the earlier mobile-pull question. Confirm before tagging it EXTERNAL-FROZEN.
- **Two publish endpoints.** `operations.py POST /publish/farm/{id}` and
  `workspace.py POST /farms/{id}/publish` both return 202. Both internal. Flag for consolidation in the
  S2.1 triage; do not freeze either.
- **Outbound payload escapes the OpenAPI.** The push shape lives in `rs_sync`, not the served spec, so
  it must be captured by `test_outbound_payload.py` or it bypasses the gate.
- **DI-1 (ingestion auth) is still open.** Freezing must not pre-empt adding auth to `/farm`; auth
  headers are additive, so document the intended end-state without blocking S4.6.
- **Determinism.** Sort keys and stabilize component ordering in the OpenAPI dump, or the diff gate
  false-positives on reordering.

## Sequencing

1. `snapshot_openapi.py` + `openapi.before.json` (S0.1a).
2. `CONTRACT.md` classification + frozen schemas + env var list (S0.1b).
3. `test_frozen_routes.py` + `test_outbound_payload.py` (S0.2a).
4. `test_openapi_diff.py` + CI wiring (S0.2b).

Each step is independently committable. The slice is done when the gate is green on current `main`
and a deliberate change to a frozen route makes it fail.
