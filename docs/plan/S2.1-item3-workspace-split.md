## New knowledge from this split

- **Multi-slice assembly.** Unlike items 1-2, the original interleaved models, services, and
  endpoints (two models were defined mid-endpoint-block), so each target module is assembled
  from disjoint line ranges. The gap check must then be computational: map every claimed line,
  assert no overlaps, and assert every unclaimed line (outside the replaced header) is blank.
  That plus a "every slice starts at column 0 with class/def/decorator" assert replaces the
  hand-enumerated gap list.
- **Router aggregation pattern.** `APIRouter.include_router` nests cleanly with no prefix, so a
  package `__init__` can present the exact same single `router` object the old module exported.
  Operation ids derive from endpoint function names (unchanged), and tags stay identical because
  each sub-router carries the same `tags=["workspace"]`. The only OpenAPI difference is path
  *ordering* in the document, which nothing checks.
- **Route-parity smoke check.** The full-path-set comparison against the committed snapshot is
  one line and proves no route was lost or accidentally added:
  `set(build_openapi()['paths']) == set(json.load(open('contract/openapi.before.json'))['paths'])`.
  It passed exactly (NONE missing, NONE new). The contract diff gate
  (`tests/contract/test_openapi_diff.py`) checks only the three frozen paths and explicitly
  ignores the BFF, so this extra check is what covers the internal routes during a BFF refactor.
- **Same-package import while `__init__` is mid-execution is fine** (third confirmation of the
  pattern): resource modules import `services.api.workspace.deps` while the package `__init__`
  is still executing its re-export imports; the partially-initialized parent in `sys.modules`
  is enough for a sibling submodule load.
- **The isort one-blank-line rule extends to plain assignments**: `deps.py` (assignments
  directly after imports) was generated with a single blank line per the items-1/2 lesson and
  passed; the one autofixed I001 this time was in the generated `__init__` (alias re-export
  ordering), not spacing. Generating `from x import a, b, router as alias` blocks: ruff sorts
  aliased members by their *original* name.

## Decisions

- **`publish.py` isolated on purpose.** The S2.1 triage flags the duplicate publish endpoints
  (`workspace POST /farms/{id}/publish` vs `operations POST /publish/farm/{id}`, both 202) for
  consolidation. That is a behavior decision (which URL survives, what the frontend calls), not
  a pure move, so it was excluded from this slice. With the pair isolated, the consolidation
  touches exactly one file plus `operations.py`.
- **Privates stay private.** `_annotation_out` and `_interpretation_out` are imported by nothing
  outside their modules, so they are not re-exported (unlike item 1's tested underscore names).
- **`fields.py` is the biggest module (238 lines)** because the field resource genuinely has
  five endpoints and four models. It is cohesive; no further split warranted.
